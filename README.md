# Survey Data Collection & Analysis

This repository contains the code for a survey project where codes are generated using Decipher tools as per client questionairre. After collecting data from the field, we analyze the data and generate reports based on client requirements.

## Features

- *Survey Questionnaire Generation*: Code is generated using Decipher tools.
- *Data Collection*: Gather responses from field surveys.
- *Data Analysis*: Process and analyze collected data.
- *Report Generation*: Generate reports as per client specifications.
